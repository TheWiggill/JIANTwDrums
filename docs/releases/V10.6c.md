# V10.6c

Public release of the USB audio input corrections tested as V10.61-fix-codex2.

- Receive EP4 OUT audio packets during audio renders, avoiding input starvation and periodic cuts.
- Keep full-scale interpolation products within signed 32-bit limits, avoiding large clicks.
- Firmware ABOUT and the public installer show V10.6c.

The source differs from the hardware-tested beta only in its displayed version. Release checks include the production TIMER5 scheduling regression, UAC tests with CDC on/off, target memory limits, pinned DSP layout, package CRC and the matching linked segment. The beta installer and its three existing packages remain available unchanged. Earlier public packages, including V10.60, remain selectable.
